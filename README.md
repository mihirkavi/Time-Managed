# Time-Managed

Front-end prototype for a web app that manages the time of an individual person or an
organisation and displays an analysis of how that time was used.

## What's inside

A static Bootstrap 3 skeleton (the pages are titled "Smart Time" and branded "Quantify")
with a shared navigation bar and three pages:

- `main.html`: home page, placeholder for the time analysis view
- `add_a_task.html`: placeholder for adding a task
- `choose_a_method.html`: placeholder for choosing a time-management method
- `main_style.css`: shared styles

The page bodies are placeholders only; there is no JavaScript logic or back end yet.

## Tech stack

HTML, CSS, Bootstrap 3.3.7, jQuery 3.1.1 and Google Fonts (all loaded from CDNs).

## Getting started

No build step is needed. Clone the repo and open `main.html` in a browser (an internet
connection is required for the CDN assets).

## Status

Early-stage prototype from March 2017; not actively maintained.
